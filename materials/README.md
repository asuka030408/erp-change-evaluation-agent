# 测试材料说明

## 使用方式

- `sources/` 是被测 Agent 可检索的材料。每份文件都有 `文档 ID`、状态、日期、适用范围和段落 ID。
- `cases/测试需求与预期.md` 是评测方使用的需求与答案要点。**不得索引进 RAG 知识库**，避免答案泄漏。
- 所有机构和姓名均为虚构。主租户为星河精密制造（`TENANT-XH`）；天衡设备（`TENANT-TH`）仅用于测试租户隔离。
- 这些材料模拟截至 2026-10-31 的资料快照。后续加入新版本时，应保留旧文件，并通过“取代”关系表示变化。

## 关键事实与冲突

星河的普通采购申请，以含税人民币金额判断阈值。现行正式规则是金额 **≤10 万元**由部门经理和采购经理审批，**>10 万元**再由财务负责人审批。2026 年 3 月的“5 万元起三级审批”只是讨论稿；4 月的正式决议确定 10 万元阈值；9 月的正式决议明确暂不降低阈值。10 月纪要又提出试点，但尚未签收。生产快照可证明当前配置，不能单独证明合同授权。

紧急采购另有已签变更单，仅适用于星河总部，并允许部门经理审批后先下单、24 小时内补齐采购经理及财务负责人审批。它不改变普通采购阈值。

## 评测口径

报告需要将“合同/已签变更单的授权”“正式会议决定”“实际配置”“未批准提案”分别表述。能否修改只能作有证据的初步判断；范围、费用、业务规则和上线由有权人员确认。证据缺失时应输出“未确认”和具体待确认问题。
